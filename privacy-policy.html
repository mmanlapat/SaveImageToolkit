Save Image Toolkit Privacy Policy

Last updated: October 1, 2026

Save Image Toolkit is a Chrome extension whose single purpose is to help users discover, save, and convert images from the webpage they are currently viewing.

Information the extension handles

When you open the extension popup or use an image right-click action, the extension may process information from the active webpage that is necessary to provide the requested feature. This can include the active page URL, image and resource URLs, page-visible image filenames, image dimensions, srcset and CSS background-image information, response metadata needed to determine an image filename or format, and the image bytes selected for download or conversion.

The extension also stores local preferences such as theme, gallery view, filters, save mode, folder-permission state, and the last resolved Chrome Downloads path. If you choose a custom folder, the browser stores a local folder handle so the extension can write files there when permission is available.

How information is used

This information is used only to provide Save Image Toolkit's user-facing image discovery, download, folder-save, and format-conversion features. The extension does not use browsing information for advertising, profiling, analytics, credit decisions, or unrelated purposes.

Network requests

When an image must be retrieved for conversion or for saving to a user-picked custom folder, the extension requests that image from its original source host. Standard browser request information, and any credentials that Chrome normally applies to that resource request, may be sent to that same source host as necessary to retrieve the image. Save Image Toolkit does not send this information or the retrieved image to the extension developer, an advertising service, an analytics provider, or a data broker.

Data sharing and sale

Save Image Toolkit does not sell user data. It does not transfer user data to the developer or to third parties for advertising, profiling, or monetization. Resource requests are made only to the original hosts needed to fulfill the user's image-saving or conversion request.

Storage and retention

Extension settings and the custom-folder handle are stored locally in Chrome on the user's device. They remain until changed, cleared, or the extension's local data is removed. The developer does not operate a server that stores this extension data.

Permissions

The extension requests only permissions required for its visible features: creating image context-menu actions, downloading files, remembering local settings, temporarily accessing the active tab, running the active-page image scanner, and retrieving image resources from their original hosts.

Chrome Web Store Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements. Save Image Toolkit uses handled data only to provide or improve its single user-facing purpose and does not use it for personalized advertising or other prohibited purposes.

Changes

If this privacy policy or the extension's data practices materially change, this page will be updated to reflect the current behavior.

Contact

For privacy questions, contact the developer using the support contact information provided on the Save Image Toolkit Chrome Web Store listing.
